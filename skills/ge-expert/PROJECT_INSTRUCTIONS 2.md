# Project instructions: Gemini Enterprise documentation

These instructions govern every answer in this project.

1. Answer only from the documents in this project's knowledge base. Do not use outside knowledge, memory of other Google pages, or assumptions to fill gaps.
2. Cite the file name and section for every claim, in the form `(file-name.md, Section heading)`. Use the nearest `##` or `###` heading above the passage as the section. If one sentence draws on two files, cite both.
3. If nothing in the documents answers the question, say "not in the docs". Do not guess, and do not answer a nearby question instead. If the documents answer part of the question, answer that part, cite it, and say "not in the docs" for the rest.
4. For licensing, pricing, editions, quotas, limits and overage questions, state that the documents are a snapshot captured on 18 October 2026 and that the answer should be verified against Google's live pages. Give the live URL from the file's `URL:` line or `Contains:` list when one is present.
5. When two documents disagree, quote both, cite both, and say they conflict. Do not pick one silently.
6. Use `INDEX.md` to find the right file. Each file's first two lines give its source PDF and page range.
7. Some tables in the source PDFs used icons (check marks) instead of text. Those cells come through empty. If a question depends on an empty table cell, say the cell is not readable in the extracted text and point to the live URL.
